Neural Network (Multi-Layer Perceptron)

โครงข่ายประสาทเทียม โครงสร้างที่ออกแบบมาสำหรับจำแนกเซลล์มะเร็ง

ทฤษฎีการทำงานและโครงสร้าง

Artificial Neural Network (ANN) หรือโครงข่ายประสาทเทียม เปรียบเสมือนการจำลองเซลล์สมองมนุษย์ประกอบด้วยโหนด (Neuron) ที่มีการเชื่อมต่อข้อมูลจาก Input ไปหา Output

สถาปัตยกรรม (Architecture) ที่เราออกแบบคือ:
  • Input Layer: โหนดรับข้อมูลจำนวน 30 ตัวแปร (ตามฟีเจอร์ของ Dataset มะเร็ง)
  • Hidden Layer 1: ประกอบด้วย 32 นิวรอน ใช้ฟังก์ชัน ReLU
  • Dropout Layer: ทำการสุ่มปิดโหนด 20% ระหว่างฝึกสอน ช่วยป้องกันระบบจำคำตอบ (Overfitting)
  • Hidden Layer 2: ประกอบด้วย 16 นิวรอน กรองข้อมูลอีกชั้นด้วย ReLU
  • Output Layer: มีจำนวน 1 โหนด ใช้ฟังก์ชัน Sigmoid บีบค่าเป็น 0-1 ว่าเป็นเนื้อดีหรือเนื้อร้าย

การฝึกสอนโมเดล (Training) อาศัยอัลกอริทึม Optimization แบบ Adam ช่วยปรับน้ำหนัก (Weights) ของแต่ละเส้นเชื่อมให้มีความผิดพลาดน้อยที่สุด

การเตรียมข้อมูลเฉพาะเจาะจง

  • Encoding: เปลี่ยน Target ให้เป็น 0 กับ 1 เพื่อให้ Output โหนดเดียวสามารถทำนายความน่าจะเป็นออกเป็นเปอร์เซ็นไทล์ได้ (Probability)
  • Feature Scaling: สิ่งสำคัญที่สุดสำหรับ Deep Learning ข้อมูลทั้งหมดที่นำเข้าถูกแปลงเป็น Normal Distribution ด้วย StandardScaler

แหล่งอ้างอิง: ทฤษฎีและตัวอย่างจาก Keras / TensorFlow Sequential Library

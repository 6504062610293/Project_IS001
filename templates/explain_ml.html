Ensemble Machine Learning Algorithm

การรวมพลังของหลายอัลกอริทึมเพื่อเพิ่มความแม่นยำในการจำแนกมะเร็งเต้านม

ทฤษฎีการทำงาน (Theoretical Background)

โมเดล Ensemble Learning เป็นการจำลองแนวคิด "การปรึกษากลุ่ม (Wisdom of crowds)" โดยนำโมเดล Machine Learning หลายๆ ตัว (Base Models) มาช่วยกันทำนายผลลัพธ์ และใช้วิธีการโหวตคะแนนเพื่อหาคำตอบที่ดีที่สุด

โมเดลที่นำมาประกอบ (Voting Classifier):
  • 1. Random Forest (RF): ใช้ต้นไม้ตัดสินใจหลายๆ ต้นมาช่วยกันจำแนกประเภทข้อมูล มีความแข็งแกร่งต่อข้อมูลรบกวน (Noise)
  • 2. Support Vector Machine (SVM): พยายามสร้างเส้นแบงแยกกลุ่มข้อมูลมะเร็งในมิติที่สูง เพื่อหากำแพงสมมติที่ดีที่สุด (Hyperplane)
  • 3. K-Nearest Neighbors (KNN): นำข้อมูลคุณลักษณะเซลล์ที่เข้ามาใหม่ ไปเทียบกับข้อมูลที่เคยพบว่าใกล้เคียงกับกลุ่มใดมากที่สุด

โมเดลใช้หลักการ Soft Voting คือ นำค่าความน่าจะเป็น (Probability) จากทั้ง 3 โมเดลมาหาค่าเฉลี่ย แทนที่จะโหวตแค่ผลลัพธ์สุดท้าย ทำให้มีความแม่นยำมากกว่าเดิม

การเตรียมข้อมูลเฉพาะเจาะจง

  • การจัดการค่าว่าง: ใช้ฟังก์ชัน Drop NA ลบข้อมูลที่ไม่สมบูรณ์ทิ้ง
  • Encoding: คอลัมน์เป้าหมาย 'diagnosis' ถูกแทนที่ M(Malignant/เนื้อร้าย) ด้วย 1 และ B(Benign/เนื้อดี) เป็น 0
  • Scaling: โมเดลอย่าง SVM และ KNN อ่อนไหวต่อสเกล จึงต้องใช้ StandardScaler ปรับข้อมูลให้ค่าเฉลี่ยเป็น 0 และการกระจายเป็น 1 เสมอ

แหล่งอ้างอิง: ข้อมูลวิจัยและทฤษฎีจาก Scikit-Learn Documentation

การทำนายค่าใช้จ่าย (Regression) ด้วยระบบผู้เชี่ยวชาญแบบจำลอง (Ensemble Machine Learning)

หลักการทำงานแบบ Ensemble

สำหรับหน้าแพลตฟอร์มนี้ โหมดการทำนายค่าใช้จ่ายประกันสุขภาพ (Healthcare Insurance) ทำงานด้วยหลักการ Voting Regressor ซึ่งเป็นการรวมผลลัพธ์จากอัลกอริทึม Machine Learning ถึง 3 ตัวเข้าด้วยกัน (เฉลี่ยคำตอบ):

  • 🌲 Random Forest Regressor: จำลองการสร้างต้นไม้ตัดสินใจหลายๆ ต้น และหาค่าเฉลี่ย
  • 📏 Support Vector Regressor (SVR): หาเส้นขอบเขตที่ครอบคลุมชุดข้อมูลที่มีความคลาดเคลื่อนยอมรับได้
  • 📡 K-Nearest Neighbors (KNN): พยากรณ์จากค่าเฉลี่ยของข้อมูลที่ใกล้เคียงที่สุดบนกราฟ 5 จุด
